🩺 1. Project Overview

Health 360 is a healthcare data analysis project that explores how patient characteristics and lifestyle factors relate to major health conditions. The interactive dashboard presents data through visualizations to make patterns easier to explore and understand.

🎯 This is an educational data analytics project. It does not diagnose patients or predict an individual's medical outcome.

🎯 2. Project Objectives

- 🔎 Explore health-related patterns across different age groups.
- 📈 Compare disease-related indicators available in the dataset.
- 🌡️ Examine BMI categories and blood-pressure categories.
- 🚬 Explore lifestyle indicators, such as smoking and physical activity.
- 📊 Present the analysis in a clear and easy-to-navigate dashboard.
- 📝 Communicate observations responsibly.

📂 3. Dataset Overview

The dataset contains 5,000 records and 16 columns.

The fields discussed during project development include:

- Age and gender
- BMI
- Exercise / physical activity
- Smoking
- Blood pressure
- Cholesterol
- Glucose
- Heart disease
- Diabetes
- Stroke

A chart comparing disease-related records across age groups to explore differences between age categories.

🌡️ 2. BMI Category × Blood Pressure Category

A heatmap showing the intersection of BMI and blood-pressure categories. The selected measure, such as record count or disease count, should be labelled clearly.

🏥 3. Disease Type Comparison

A chart comparing available disease indicators, such as heart disease, diabetes, and stroke.

🏃 4. Lifestyle vs Disease

A chart exploring lifestyle indicators, such as exercise and smoking, alongside disease-related fields. These patterns do not prove that a lifestyle factor caused a disease.
